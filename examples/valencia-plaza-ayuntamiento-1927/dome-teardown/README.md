# Cúpula de vidriera — despiece 3D interactivo (three.js)

Página única (`index.html`, sin dependencias externas salvo la tipografía) con la cúpula del patio de
operaciones del Palacio de Comunicaciones (reconstrucción) despiezada pieza a pieza: 257 piezas
(48 sillares, 24 piezas de cornisa, anillo de arranque y 32 pernos, 16 nervios, anillos, 96 paneles de
vidrio emplomado, medallón con el escudo, linterna y remate).

- Slider y botón de despiece (escalonado por orden de montaje inverso), guías punteadas, corte,
  etiquetas, giro, rayos X y secuencia de montaje paso a paso (9 pasos).
- Toca una pieza: se aísla, el resto queda atenuado y aparece su ficha (material, medidas, masa, función).
- Las medidas y el reparto de piezas son estimaciones verosímiles, no un levantamiento.

```bash
npm install && npm run build   # genera index.html
```
